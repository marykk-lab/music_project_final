# 🎵 Music Player System

A **FastAPI**-powered web application for saving and managing music collections.  
Users can create playlists, add songs, play them, update details, and delete entries — full CRUD functionality.  

The frontend is served using **HTML + CSS** templates (Jinja2). 
Data is stored in **SQLite**.

## ✨ Features

- 🎶 Add new songs with metadata (title, artist, album, etc.)  
- 📝 Edit song, profile details (CRUD operations)  
- 🗑️ Delete songs from playlist  
- 🎧 Play songs directly from the browser using HTML5 audio  
- 💻 Simple, responsive HTML + CSS interface

---

## 🛠 Tech Stack

- **Backend:** FastAPI (Python)  
- **Database:** SQLite  
- **Frontend:** HTML, CSS (Jinja2 templates)  
- **Deployment:** Docker & docker-compose
